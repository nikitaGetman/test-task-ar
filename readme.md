# Trading Bot

## Описание

Данный проект представляет собой спотового торгового бота для работы с Binance API. Бот реализует стратегию торговли с использованием веб-сокетов для получения данных о ценах и пользовательских потоков, с выполнения ордеров в зависимости от заданных условий.

## Параметры настройки

Параметры настройки можно задать тремя способами (в порядке приоритета):

1. **Консольные аргументы**
2. **Переменные окружения, указанные через консоль**
3. **Файл `.env`**

### Переменные настройки из `settings.py`:

-   `BINANCE_KEY`: API ключ Binance.
-   `BINANCE_HMAC_SECRET`: HMAC секретный ключ (строка или путь к файлу PEM).
-   `BINANCE_RSA_SECRET`: RSA секретный ключ (строка или путь к файлу PEM).
-   `PRIVATE_KEY_PASSPHRASE`: Пароль для расшифровки приватного ключа (если требуется).
-   `IS_TESTNET`: Флаг использования тестовой сети Binance (по умолчанию `True`).
-   `SYMBOL`: Торговая пара (например, `BTCUSDT`).
-   `AMOUNT`: Количество токенов для покупки.
-   `STOP_LOSS_PERCENT`: Процент для стоп-лосса.
-   `TAKE_PROFIT_PERCENT`: Процент для тейк-профита.
-   `TIMEOUT_SEC`: Таймаут в секундах для ожидания выполнения условий.
-   `DELAY_BETWEEN_TRADES_SEC`: Задержка между сделками в секундах.

### Примеры задания параметров:

#### Через консольные аргументы:

```bash
python -m bot --BINANCE_KEY your_api_key --SYMBOL BTCUSDT --AMOUNT 0.01
```

#### Через переменные окружения:

```bash
BINANCE_KEY=your_api_key SYMBOL=BTCUSDT python -m bot
```

#### Через файл `.env`:

```env
BINANCE_KEY=your_api_key
SYMBOL=BTCUSDT
AMOUNT=0.01
```

## Поддерживаемые секретные ключи

Бот поддерживает несколько типов секретных ключей:

-   **HMAC**: Передается как строка или путь к файлу PEM.
-   **RSA**: Передается как строка или путь к файлу PEM.
-   **ED25519** ~~:В разработке~~.

### Примеры:

#### HMAC ключ:

-   Строка: `BINANCE_HMAC_SECRET=my_hmac_secret`
-   Путь к файлу: `BINANCE_HMAC_SECRET=./keys_example/hmac_secret.pem`

#### RSA ключ:

-   Строка: `BINANCE_RSA_SECRET=my_rsa_secret`
-   Путь к файлу: `BINANCE_RSA_SECRET=./keys_example/rsa_4096_private.txt`

## Поддержка автоматического retry

Бот поддерживает автоматический retry при ошибках в API контроллере. Если запрос к Binance API завершился с ошибкой (при проблемах сети или сервера), бот повторит попытку выполнения запроса.

## Алгоритм работы

### При старте приложения:

1. Загружаются настройки из консольных аргументов, переменных окружения или файла `.env`.
2. Устанавливается соединение с Binance API.
3. Инициализируется стратегия торговли.

### В цикле основной стратегии:

1. Подписка на пользовательский канал данных с информацией о выполненных ордерах.
2. Покупка заданного количества криптовалюты в случайный момент времени.
3. Отслеживание цены:
    - Если цена опустилась ниже заданного процента (`STOP_LOSS_PERCENT`), актив продается с убытком с помощью OCO STOP_LOSS ордера.
    - Если цена поднялась выше заданного процента (`TAKE_PROFIT_PERCENT`), актив продается с прибылью с помощью OCO TAKE_PROFIT ордера.
    - Если в течение заданного времени (`TIMEOUT_SEC`) условия не выполнены, актив продается по рыночной цене.
4. После продажи ждет заданный интервал (`DELAY_BETWEEN_TRADES_SEC`) и повторяет цикл.
